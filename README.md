# VOLT // 无畏经理人

一个纯静态、可直接部署到 GitHub Pages 的 VALORANT 经理人游戏原型。玩家从零开始管理独立战队 VOLT Academy，完成招募、赛事、训练、战术和俱乐部经营。

## 功能
- 管理中心：预算、声望、化学反应、全球排名、比赛与联盟动态
- 选手市场：基于真实 VCT CN 选手昵称、定位与战队背景的招募卡片
- 赛程与赛事：VCT CN、Masters、Champions 赛历与赛程
- 战术实验室：训练计划开关、地图胜率与团队建设
- 俱乐部：设施、赞助、阶段目标
- 响应式布局，移动端可用；无需后端和构建工具

## 部署到 GitHub Pages
1. 将本目录内容推送到 `laogaofirefly/Valorant-manager-v2` 的 `main` 分支。
2. GitHub → Settings → Pages → Deploy from a branch → `main` / `/ (root)`。
3. 等待部署完成，地址通常为 `https://laogaofirefly.github.io/Valorant-manager-v2/`。

> 游戏内赛事、选手信息按 VCT 生态做了真实感设定；正式商业发布前请确认 Riot Games / VALORANT 的商标与素材使用许可。
